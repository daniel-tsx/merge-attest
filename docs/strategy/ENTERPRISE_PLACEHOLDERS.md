# Enterprise Placeholders

**Status:** `current` (planning)
**Location:** `docs/strategy/ENTERPRISE_PLACEHOLDERS.md`

These capabilities are intentionally deferred until there is clear customer demand.

## Deferred Capabilities

- SSO and SAML configuration.
- SCIM user provisioning.
- IP allowlists.
- Custom audit retention contracts.
- Slack and Microsoft Teams alerting.
- Public customer API tokens and API access policies.
- Self-hosted deployment packaging.
- Multi-provider source control support beyond GitHub.

## Decision Rule

Add an enterprise capability only when at least one real customer has a concrete requirement, acceptance criteria, and willingness to validate the workflow.

Until then, keep the app focused on core AI pull request risk, approval, policy, billing, reporting, and diagnostics workflows.
