# Product

## Register

product

(The app UI is the primary surface. Marketing surfaces — `/`, `/privacy`, `/terms`, auth shell — switch to the brand register per task.)

## Users

Engineering leads, platform engineers, and security/compliance owners at teams shipping AI-assisted code (Cursor, Copilot, Claude Code, Codex, Devin). Context: pull request volume from coding agents outpaces careful human review; auditors and frameworks (EU AI Act human-oversight, SOC2) are starting to ask for AI-authorship evidence. They evaluate tools skeptically and distrust AI-washing.

## Product Purpose

MergeAttest is a GitHub-native control center for AI-assisted pull requests: it attributes every PR to the agent that wrote it (with confidence and evidence), scores risk deterministically, detects missing tests, evaluates repository rules, records human approvals, and exports audit evidence. Launch posture: free early access, no public pricing. Success = installed GitHub Apps and governed repositories.

## Brand Personality

Operational, exact, governance-oriented. "An engineering control room, not a friendly workspace editor." Linear-influenced precision: restrained color, crisp hairline borders, compact density, sparse elevation. Trust is earned by showing deterministic mechanics, not by claiming intelligence.

## Anti-references

- Generic AI-product cues: decorative pills, colorful agent badges, purple gradients, oversized abstract 3D blobs, labels that merely say "AI".
- SaaS-template landing pages: centered icon-title-text card grids, hero-metric clichés, fake logo walls or invented social proof (product is pre-customer early access).
- Linear-gradient decorative backgrounds (explicit owner rule).

## Design Principles

1. Deterministic controls feel primary; advisory AI is a supporting layer, never the visual center.
2. Show the mechanism: real product surfaces (scan, scores, ledger, audit trail) beat abstract illustration.
3. Precision is the aesthetic: alignment, tabular numerals, mono micro-labels, hairline borders.
4. The page itself must feel audited — exact copy, no hype adjectives, evidence over claims.

## Accessibility & Inclusion

Visible `focus-visible` rings on all interactive controls; global `prefers-reduced-motion` kill-switch must cover every animation; decorative icons `aria-hidden`; readable contrast in both light and dark themes; no hover-only interactions.
